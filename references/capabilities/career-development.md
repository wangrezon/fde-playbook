# 职业发展（晋升双通道 + 是否做 FDE + 个人止损）

## R — 原文 (Reading)

> 第一，学习价值曲线连续两个季度走平，可以主动申请轮换客户。第二，每个季度盘点一次：这个季度我形成了哪些今后还能复用的积累？第三，如果身体和情绪已经发出明确信号，就不要继续硬扛。
>
> — 曹犟，第 23 讲

## I — 方法论骨架 (Interpretation)

FDE 的职业发展三个判断工具：

**晋升双通道**：留住资深 FDE 需建两条通道——技术专家路线（继续做深，资深个人贡献者、技术兜底）与客户战略路线（扩大负责范围，更大客户、行业线/客户组合）。选路看两点：成就感来源（客户沟通后更有精力 vs 明显疲惫）与长期想积累什么（架构集成生产化 vs 行业理解客户经营）。FDE 晋升不表现为管的人变多，而表现为负责的客户更复杂、承担结果更大。

**是否做 FDE（三张清单）**：去乙方问五问（多少客户/有无承接现场学习的平台基础/销售 pipeline 稳不稳/创始人还亲自见客户吗/工程团队是否重视客户现场）；留甲方问四问（有无足够多真实场景/有无知识库平台承接认知/能否获得数据权限反馈/出结果后有无愿给场景的负责人）；看自己问三问（能否接受长期出差/能否承受不确定性复杂关系/长期与人沟通后更有精力还是影响生活）。

**个人止损三判据**（作者注明是经验值非硬标准）：①学习价值曲线连续两季走平，主动申请轮换客户，不批就认真考虑换环境；②每季度盘点「形成了哪些今后还能复用的积累」；③身体情绪发出明确信号就不硬扛。

## A1 — 应用示例 (Application Example)

### 示例 1：倦怠死亡螺旋（反例）
- **类型与来源**: 原书反例，第 18 讲
- **问题/输入**: 资深 FDE 长期钉在同一客户上，连续两季无新学习产出
- **方法论的使用**: 用个人止损三判据反查——学习价值曲线走平却没轮换，倦怠从最资深的人率先爆发
- **结论**: 「越缺人越倦怠、越倦怠越缺人」的死亡螺旋
- **结果**: 未说明（作为失败模式）

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 资深 FDE 觉得没成长了，考虑去留
2. 想转行做 FDE，但不确定适不适合
3. 老板要设计 FDE 的晋升通道
4. 身体/情绪已经疲惫，纠结要不要继续硬扛

### 语言信号 (用户的话里出现这些就应激活)

- 「FDE 怎么晋升」「技术路线还是客户路线」「我适不适合做 FDE」
- 「该不该离职」「学习曲线走平了怎么办」「倦怠了要不要硬扛」
- 英文: "FDE career path", "promotion track", "burnout", "should I be an FDE"

### 与相邻 skill 的区分

- 与 `capability-interview` 的区别：本卡是「晋升 + 去留 + 个人止损」，后者是「能力自评 + 面试 + 入职」。
- 与 `failure-identification` 的区别：本卡的「个人止损三判据」是个人层面，后者是团队/公司层面的六大失败模式。

## E — 可执行步骤 (Execution)

**必需输入**: 个人当前状态（成就感来源、学习曲线、身心信号）或公司晋升通道现状。缺「成就感来源」判断时先回顾「客户沟通后更有精力还是更疲惫」。

**交付物与完成标准**: 一个职业判断（选哪条路 / 去留 / 是否止损）+ 季度积累盘点。

1. **选晋升通道**
   - 完成标准: 按成就感来源 + 长期积累方向，选技术专家路线或客户战略路线。
2. **过三张清单**
   - 完成标准: 乙方五问/甲方四问/个人三问逐项，判断「这条路值不值得走」。
3. **个人止损三判据**
   - 完成标准: 学习曲线（连续两季走平→轮换）、季度积累盘点、身心信号三判据逐查。
4. **输出职业判断**
   - 完成标准: 选路 + 去留 + 止损动作明确，落到书面。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 能力自评 + 面试准备——那是 capability-interview 的职责
- 团队/公司的失败模式体检——那是 failure-identification 的职责
- 具体薪酬数字谈判——本卡给方向不给数字

### 作者在书中警告的失败模式

- 倦怠死亡螺旋：最资深的人往往最先离开，因为学习价值递减 + 压力递增。

### 作者的盲点 / 时代局限

- 作者自身是清华系 + 独角兽 CTO 背景，「一个人打穿全链路」对普通从业者距离感强，对「够不到门槛的人」路径偏薄弱。

### 容易混淆的邻近方法论

- 个人止损三判据与公司层服务陷阱是同一逻辑：公司不沉淀会退化成外包，个人只出工不沉淀也会把自己变成只能重复交付的人。
