# 失败识别与止损

## R — 原文 (Reading)

> 这三个条件同时满足时就启动退出评估：项目失去核心赞助人，三个月内仍找不到新的支持者；真实使用量持续下降，却找不到原因；项目中可复用的资产已经基本提炼出来。
>
> — 曹犟，第 18 讲

## I — 方法论骨架 (Interpretation)

失败有稳定类型，风险有可观察信号。两个工具：

**六大失败模式**（体检表）：咨询陷阱、每客户雪花化、英雄工程师、demo 债务螺旋、赞助人崩塌、倦怠死亡螺旋。每种都有征兆、机制、防线。

**四信号复合预警仪表盘**（每季度查一次）：客户专属代码持续增加、新客户部署周期持续缩短、资深工程师流失率上升、高管储备减少。单看一个恶化不致命，四个负面同时出现=系统性风险。注意「部署周期缩短」反直觉：若与另三信号同现，快多半来自复制定制代码或省略硬化，实为雪花化/demo 债务加重。

**项目级止损三条件**（同时满足即启动退出评估）：失去核心赞助人且三月内无新支持者；真实使用量持续下降查无因；可复用资产已基本提炼完。实操细节：退出评估不让项目负责人主持（沉没成本绑架判断），换交付线之外的人牵头。第三条意味着项目商业失败但资产可赚。

## A1 — 应用示例 (Application Example)

### 示例 1：IBM Watson 赞助人崩塌（转述）
- **类型与来源**: 原书转述，第 18 讲
- **问题/输入**: MD 安德森项目四年 6200 万美元，2015 年核心赞助人 Lynda Chin 离职
- **方法论的使用**: 用「赞助人崩塌」模式识别——高调启动→期望升高→赞助人离开→进入审计
- **结论**: 组织层面的失败在技术甚至未获临床检验前就发生
- **结果**: 系统从未用于任何患者，项目进入审计（审计只查采购超支与治理，不评价技术）

### 示例 2：四信号同时恶化（合成演练，规则可复算）
- **类型与来源**: 原书未提供完整案例，以下为合成演练
- **问题/输入**: 某团队季度体检：客户专属代码增、部署周期缩短、资深工程师流失、高管储备减
- **方法论的使用**: 四信号组合看——单看部署周期缩短像好事，四信号同现判系统性风险（复制定制代码/省略硬化）
- **结论**: 启动系统性干预，而非局部修补
- **结果**: 合成演练输出，非作者经历

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 想给团队/公司做一次「FDE 健康体检」
2. 项目陷入困境，判断该不该止损
3. 复盘连续失败，想找出稳定的失败类型
4. 老板问「我们的 FDE 团队是不是出问题了」

### 语言信号 (用户的话里出现这些就应激活)

- 「FDE 失败有哪些模式」「怎么识别失败预警信号」「项目该不该止损」
- 「咨询陷阱/雪花化/英雄工程师/demo 债务/赞助人崩塌/倦怠螺旋」
- 英文: "failure modes", "warning signals", "stop loss", "project exit", "burnout"

### 与相邻 skill 的区分

- 与 `retrospective` 的区别：本卡是「失败模式体检与止损」，retrospective 是「单项目五步复盘」。
- 与 `service-trap` 的区别：本卡覆盖「六大失败模式」全景，service-trap 只聚焦「服务陷阱」这一个经营层失败。
- 与 `stakeholder-map` 的区别：本卡的「赞助人崩塌」是失败模式识别，stakeholder-map 是预防性布局。

## E — 可执行步骤 (Execution)

**必需输入**: 团队/项目的体检数据（代码增量、部署周期、流失率、高管储备）。缺数据时先建季度体检指标，不凭印象判断。

**交付物与完成标准**: 一份失败模式体检表（六类逐项）+ 四信号仪表盘读数 + 止损判断。

1. **六类失败模式体检**
   - 完成标准: 六类逐一核对征兆，标出命中项。
2. **读四信号仪表盘**
   - 完成标准: 四信号各有季度数据，组合判断是否系统性风险。
3. **过项目止损三条件**
   - 完成标准: 三条件逐查；同时满足 → 启动退出评估。
4. **退出评估换人主持**
   - 完成标准: 退出评估由交付线之外的人牵头，避免沉没成本绑架。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 单项目正常结项复盘——那是 retrospective 的职责
- 要建立沉淀机制防失败——那是 sediment-pipeline 的职责
- 个人层面的职业去留判断——那是 career-development 的个人止损三判据

### 作者在书中警告的失败模式

- 六大失败模式不是一次性错误决策，而是「看似合理的决策逐步滑入」——不能等亏损失控才识别。
- 「部署周期缩短」可能被误判为好事，需组合其他信号看。

### 作者的盲点 / 时代局限

- 四信号仪表盘是「经验归纳」，未给各信号的量化阈值，需自行设定「恶化」的判据。

### 容易混淆的邻近方法论

- 与「中国六道坎」的区别：六道坎是「放大失败的结构性现实条件」（利润/人才/晋升/抽象/组织/市场），不是失败类型本身——本卡回答「出了什么问题」，六道坎回答「为什么总会出」。
