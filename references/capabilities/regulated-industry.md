# 强监管行业三笔商业账

## R — 原文 (Reading)

> 这个过程可以用三笔商业账来解释：预算账回答客户为什么愿意买，采购账回答合格供应商为什么站得住，规模账回答后续项目为什么能够复制。
>
> — 曹犟，第 19 讲

## I — 方法论骨架 (Interpretation)

强监管行业「门槛高却仍能规模化」，用三笔账解释：

- **预算账**（客户为什么愿意买）：治理需求刚性，有合规预算与付费能力，治理能力可单列报价；
- **采购账**（合格供应商为什么站得住）：合规/安全部门参与购买，跨过门槛的合格供应商供给少、切换成本高、合作周期长；
- **规模账**（后续项目为什么能复制）：审计要求/审批流程/合规规则沉淀成产品配置与模板，第一个客户投入在后续客户转成可复用能力。

关键结论：高门槛本身不带来规模，刚性需求 + 有限供给 + 可复用才成立。在强监管行业，「治理就是产品」——把模型/数据/代码/决策权的控制要求做成可报价、可交付、可验收、可复用的产品能力。

## A1 — 应用示例 (Application Example)

### 示例 1：诺和诺德用 Claude Code 建监管文档平台（转述）
- **类型与来源**: 原书转述，第 19 讲
- **问题/输入**: 丹麦药企诺和诺德要写监管级文档
- **方法论的使用**: 文本密集+合规密集场景用「AI 先生成、人再审核」；主导者是非工程的分子生物学博士
- **结论**: AI 降低了动手门槛，治理能力本身成了可交付产品
- **结果**: 文档撰写从十几周缩到十分钟，设备验证协议工作量从一整个部门降到一人，审查周期降一半

### 示例 2：BBVA 灰度扩展（转述）
- **类型与来源**: 原书转述，第 19 讲
- **问题/输入**: 西班牙 BBVA 与 OpenAI 合作，金融强监管
- **方法论的使用**: 先 3300 名员工试用、看到持续使用+降本后逐步扩范围，每轮扩展基于上一轮真实使用数据
- **结论**: 规模账——治理与合规沉淀成可复用模板，逐轮扩展
- **结果**: 最终覆盖 12 万名员工

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 要进入金融/政企/医疗等强监管行业做 FDE
2. 判断「这个强监管客户值不值得做重」
3. 客户问「治理/合规能力能不能单独报价」
4. 想把治理能力沉淀成可复用产品

### 语言信号 (用户的话里出现这些就应激活)

- 「强监管行业怎么做 FDE」「治理怎么变成产品」「金融/医疗/政企落地」
- 「三笔账」「合规能不能单独报价」
- 英文: "regulated industry", "governance as product", "compliance moat", "financial services FDE"

### 与相邻 skill 的区分

- 与 `service-trap` 的区别：本卡是「强监管行业的经济逻辑」，service-trap 是「通用防外包化经营判断」。
- 与 `go-live` 的区别：本卡的「治理即产品」是行业定位，go-live 是「上生产的治理方案落地」。
- 与 `industrial-rule-model`、`customer-service-authorization` 的区别：三张卡是 task-17 按行业拆的三种落地方法，本卡对应金融/政企/医疗。

## E — 可执行步骤 (Execution)

**必需输入**: 目标行业的治理需求 + 客户预算/付费能力 + 合格供应商竞争格局。缺「合规需求是否刚性」判断时先调研客户是否有合规预算与付费意愿。

**交付物与完成标准**: 一个「值不值得做 + 怎么规模化」的行业判断（三笔账各一段）。

1. **算预算账**
   - 完成标准: 客户治理需求刚性 + 有合规预算/付费能力，治理能力可单列报价。
2. **算采购账**
   - 完成标准: 合格供应商供给少、切换成本高、合作周期长的判断有依据。
3. **算规模账**
   - 完成标准: 审计/审批/合规规则可沉淀成产品配置与模板，第一个客户投入可复用。
4. **收敛结论**
   - 完成标准: 刚性需求+有限供给+可复用三者是否成立，给出行业判断。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 非强监管行业（无合规刚需）——三笔账的前提不成立
- 要落地具体治理方案——那是 go-live 的职责
- 要判断公司整体是否滑向服务陷阱——那是 service-trap 的职责

### 作者在书中警告的失败模式

- 把「治理=合规成本」当常识，会把治理当待压缩项，错失强监管行业真正的付费点和护城河。

### 作者的盲点 / 时代局限

- 三笔账依赖大量 2025–2026 年财务/监管数据，这些数字快速过时，作为「证据」的时效有限，需用当下数据复核。

### 容易混淆的邻近方法论

- 「高门槛」≠「能规模化」：门槛本身不带来规模，刚性需求+有限供给+可复用三者齐备才成立。
