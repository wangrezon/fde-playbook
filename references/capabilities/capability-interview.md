# 能力模型与面试

## R — 原文 (Reading)

> 第一个切面是"一纵"，指的是技术深度……第二个切面是"一横"，指的是能力广度……第三个切面是"一软"，其实就是把种种现场软实力单独拿出来。
>
> — 曹犟，第 22 讲

## I — 方法论骨架 (Interpretation)

FDE 能力用三个切面看：

- **一纵（技术深度）**：生产级编程、数据工程、云与基础设施、安全合规四项均须资深，且「看最低分不看平均分」；
- **一横（能力广度）**：软件工程、AI 与机器学习、集成、交付、沟通五个能力簇，纯技术只占两个半，需对全产品约 70% 了解；
- **一软（现场软实力）**：干系人、汇报、怀疑者管理，重要到单独成切面。

结论：FDE 可有面向新人的岗位，但无入门级职责。**四轮面试**把复合能力拆开验证：编码（考生产级重构/集成，非算法谜题）、系统设计（跨云跨栈从第一性原理搭架构）、问题分解（MECE 拆模糊问题，考先澄清目标→拆场景→北极星排序→定第一步怎么验证）、客户模拟（扮演怀疑型干系人，先理解情绪再问在意什么）。四轮不取平均，而是四个信号定性判断，一轮特别差（尤其第四轮）很难被其他轮救回。

**30-60-90 入职**：前 30 天跟资深 FDE 观察完整交付链路；31-60 天指导下负责小块边界清楚的交付任务；61-90 天主导低风险客户接触。不是熬资历，而是逐步扩大责任边界。

## A1 — 应用示例 (Application Example)

### 示例 1：四轮面试的问题分解轮（合成演练，规则可复算）
- **类型与来源**: 原书给出四轮结构、未给完整实录，以下为合成演练
- **问题/输入**: 候选人面对「帮客户提高广告 ROI」的模糊问题
- **方法论的使用**: 问题分解轮——先澄清目标（什么算 ROI 提升）→拆场景（渠道/品类）→北极星三条件排优先级→定第一步怎么验证
- **结论**: 考的是「把模糊问题拆清楚」的能力，而非算法
- **结果**: 合成演练输出，非作者经历

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 要招一个 FDE，不知道按什么标准面
2. 自评「我够不够格做 FDE」，想找短板
3. 新人 FDE 入职，要规划前 90 天的培养节奏
4. 团队里 FDE 能力参差，想做能力盘点

### 语言信号 (用户的话里出现这些就应激活)

- 「FDE 需要什么能力」「一纵一横一软」「FDE 怎么面试」
- 「四轮面试」「新人 FDE 怎么带」「30-60-90」
- 英文: "FDE competency", "FDE interview", "four round interview", "onboarding 30-60-90"

### 与相邻 skill 的区分

- 与 `career-development` 的区别：本卡是「能力自评 + 面试 + 入职」，career-development 是「晋升通道 + 去留判断」。
- 与 `genuine-check` 的区别：本卡评估「个人能力」，genuine-check 判断「岗位/团队真假」。

## E — 可执行步骤 (Execution)

**必需输入**: 候选人（招聘）或自评（自我盘点）。缺「能力缺口」时先按三切面逐项打分。

**交付物与完成标准**: 一份三切面能力自评/评估 + 四轮面试方案 + 30-60-90 入职计划。

1. **三切面评估**
   - 完成标准: 一纵（4 项技术看最低分）、一横（5 簇）、一软逐项打分，标出短板。
2. **四轮面试拆开验证**
   - 完成标准: 编码/系统设计/问题分解/客户模拟四轮各有题目；四轮定性判断不取平均。
3. **定入职节奏（30-60-90）**
   - 完成标准: 前 30 天观察、31-60 天小块任务、61-90 天低风险客户接触，责任边界逐步扩大。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 判断岗位是不是真 FDE——那是 genuine-check 的职责
- 晋升/去留/职业方向——那是 career-development 的职责
- 评估候选人的通用工程能力（与本岗位无关的算法刷题）——四轮面试明确排斥算法谜题

### 作者在书中警告的失败模式

- 按「技术栈清单」评估 FDE 会漏掉一横的集成/交付/沟通与一软，误判候选人。
- 四轮取平均会掩盖「一轮特别差（尤其客户模拟轮）」的致命短板。

### 作者的盲点 / 时代局限

- 作者自承这是参考结构，「国内企业未必按此四轮考察」。能力门槛「八分之一」是精英叙事，对普通从业者距离感强。

### 容易混淆的邻近方法论

- 「一纵看最低分」与「四轮不取平均」是同一逻辑：FDE 是复合能力，短板决定上限，不能用平均分掩盖单点硬伤。
