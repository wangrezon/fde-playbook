# 决策规则速查 — 《FDE 业务落地实战课》

| 能力 | 一句话规则 |
|---|---|
| 真假 FDE 判断 | 判断真假 FDE 只看两条硬线：现场认知是否回流产品、第二个客户是否做得更容易。 |
| 进场前判断（立项四问 + 客户四问） | 进场前过两道关：立项四问（负责人/预算/指标/退出条件）+ 客户四问（引路人/数据权限/反馈周期/谁买单）。 |
| 五天摸真问题 | 进场第一周五动作（坐旁边/亲手干/合成数据挑逗/挖阻塞点/分清真问题），再过五标准筛真问题。 |
| 翻译问题 + 北极星三条件 | 把「想要什么」翻译成「什么变化 + 哪个数字」，再让指标过北极星三条件（强相关/可影响/可归因）。 |
| 用例优先级表 | 价值链找场景 + 五维打分（价值/可行/速度/风险/被采纳）+ 做/延后/放弃三档，敢写放弃。 |
| 干系人地图 + 怀疑者/赞助人管理 | 干系人地图四问（拍板/否决/需知/在意）+ 三类人三打法 + 怀疑者给角色、赞助人至少两个。 |
| 汇报金字塔 + MECE | 结论先行 → 两三条理由 → 证据细节，理由间 MECE（不重叠不遗漏）。 |
| demo 驱动开发（MVP + MVA + 每周 demo） | 端到端最小单元「宁可窄不可断」，MVP 验价值 + MVA 验可行性，每周 demo 把模糊反馈逼成工单。 |
| 施工纪律（gap 四象限 + 代码三区） | gap 四象限（通用/特有 × 阻塞/增强）+ 代码三区（负债/隔离/资产），尽量往隔离区和资产区推。 |
| 集成与迁移三动作 | 连线变清单 + 先通最细真实链路 + 迁移先彩排定对账标准。 |
| 私有化版本纪律 | 大版本一年半/中版本季度只改元数据/小版本周只修问题，版本号写进合同。 |
| 四层知识库 | 知识分四层（产品使用/跨行业共性/行业特有/企业特有），天花板是知识结构不是模型。 |
| 安全护栏五件套 | 字段级权限/明细脱敏/操作白名单+最小权限/审计/回执确认+可回滚，护栏第一天焊死。 |
| 评估驱动开发 | 先定义「好」再写第一行 prompt，三类评估集 + 棘轮原则 + 评估面/客户面分工。 |
| 上生产（六项检查 + 治理 + 留痕 + HITL） | 六项检查 + 五类治理风险双列负责人 + 全链路留痕 + HITL 三级，灰度上线。 |
| 沉淀管道（内环外环 + 平台提交 + 前后方握手） | 内环交付价值、外环固化产品；平台提交四要素 + 前后方握手固定周会，沉淀不能靠自觉。 |
| 自治阶梯（交接） | 交接三步（FDE 主导 → 客户运营+FDE 后方 → 客户独立），毕业标准看客户团队是否接得住。 |
| 私有知识四步转化 | 抽取/脱敏/结构化/入库四步 + 边界三问，把 know-how 从脑子变公司资产。 |
| 定价（OLA + RaaS + 客单价匹配） | OLA 四要素（结果/衡量/负责人/审核节奏）+ RaaS 基础费+效果分成 + 轻/中/重 FDE 匹配客单价。 |
| 服务陷阱（a16z 四条件 + 毛利换护城河） | a16z 四条件（关键/集中/共同模式/门槛）+ 毛利换护城河三边界，关键在「换」。 |
| 五步复盘 | 目标/实际结果/差距归因/可复用资产/下一步五步，分水岭在第四步可复用资产。 |
| 失败识别与止损 | 六大失败模式体检 + 四信号复合仪表盘 + 项目级止损三条件，退出评估换人主持。 |
| 强监管行业三笔商业账 | 预算账/采购账/规模账三笔账，治理即产品，高门槛本身不带来规模。 |
| 制造/能源：规则/模型划界 + 数据地基 | 确定性归规则、概率归模型（三步划界）+ 数据地基三检查，概率输出过确定性闸门。 |
| 客服授权三级 + 降级 | 答得准/能动手/敢托付三级，每上一级护栏加一层，降级机制提前设计。 |
| 能力模型与面试 | 一纵一横一软三切面 + 四轮面试不取平均 + 30-60-90 逐步扩大责任边界。 |
| 职业发展（晋升双通道 + 是否做 FDE + 个人止损） | 晋升双通道（技术专家/客户战略）+ 乙方五问/甲方四问/个人三问 + 个人止损三判据。 |

> 速查只给结论；需要原文依据、案例或反例时读对应能力卡。
